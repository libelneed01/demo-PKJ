# Pesona Khayangan Juanda (prototype demo)

## Jalankan lokal
```bash
npm install
npm run dev
```
Buka http://localhost:3000

## Deploy ke Vercel (gratis)
1. Push folder ini ke repo GitHub.
2. Masuk ke vercel.com, klik "Add New Project", pilih repo tersebut.
3. Biarkan pengaturan default (Next.js terdeteksi otomatis), klik Deploy.

Alternatif lewat CLI: `npx vercel` lalu ikuti petunjuknya.
